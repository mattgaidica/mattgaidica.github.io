CV API

Static JSON endpoints for agents and tools. No auth. Regenerated whenever cv.yaml is rebuilt.

Endpoints

  • GET /cv/api/v1/index.json — discovery
  • GET /cv/api/v1/cv.json — full structured CV
  • GET /cv/cv.yaml — YAML source
  • GET /cv/GAIDICA_WashU_CV.docx — WashU Word CV
  • GET /cv/GAIDICA_WashU_CV.pdf — PDF

Quick start

curl -s https://gaidi.ca/cv/api/v1/cv.json | jq '.profile'
curl -s https://gaidi.ca/cv/api/v1/index.json | jq '.endpoints'

See cv/README for the edit → build pipeline.
